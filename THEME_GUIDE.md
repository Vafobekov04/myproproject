# 🎨 Руководство по темам приложения

## Обзор

Приложение Sales Management System поддерживает две встроенные темы:
- **Светлая тема** (Light) - классический светлый интерфейс с белым фоном
- **Темная тема** (Dark) - современный темный интерфейс для работы в условиях низкой освещенности

## Переключение темы

### В приложении

1. Нажмите кнопку **🌙 (Луна)** в боковой панели (слева сверху)
2. Тема переключится на противоположную
3. Кнопка изменится на **☀️ (Солнце)**

Повторное нажатие вернет вас на предыдущую тему.

### Сохранение предпочтения

Выбранная тема автоматически сохраняется в файл конфигурации:
- **Расположение**: `~/.sales_system/theme.json`
- **Формат**: JSON
- При следующем запуске приложения будет использована сохраненная тема

## Особенности каждой темы

### Светлая тема
- ✅ Хорошая видимость при дневном свете
- ✅ Классический профессиональный вид
- ✅ Идеальна для печати документов
- 🎨 Основные цвета: белый, серый, синий акцент

### Темная тема
- ✅ Снижает нагрузку на глаза при работе в темноте
- ✅ Экономит энергию батареи (особенно на OLED экранах)
- ✅ Современный внешний вид
- 🎨 Основные цвета: темно-серый, темно-синий, голубой акцент

## Технические детали

### Файл ThemeManager

Находится в: `utils/theme_manager.py`

**Основные функции:**
- `set_theme(theme_name)` - установить тему
- `get_theme()` - получить текущую тему
- `get_colors()` - получить палитру цветов
- `get_stylesheet()` - получить CSS стили для текущей темы

### Цветовые схемы

#### Светлая тема
```python
"light": {
    "bg_primary": "#FFFFFF",      # Основной фон
    "bg_secondary": "#F5F5F5",    # Вторичный фон
    "text_primary": "#1A1A1A",    # Основной текст
    "text_secondary": "#666666",  # Вторичный текст
    "accent": "#0066CC",          # Цвет акцента
    ...
}
```

#### Темная тема
```python
"dark": {
    "bg_primary": "#1E1E1E",      # Основной фон
    "bg_secondary": "#2D2D2D",    # Вторичный фон
    "text_primary": "#E0E0E0",    # Основной текст
    "text_secondary": "#999999",  # Вторичный текст
    "accent": "#4A9EFF",          # Цвет акцента
    ...
}
```

## Добавление новых элементов с поддержкой тем

Все стили управляются через `ThemeManager`. Следуйте этому примеру:

```python
from utils.theme_manager import ThemeManager

# В вашем окне
self.theme_manager = ThemeManager()
self.setStyleSheet(self.theme_manager.get_stylesheet())
```

При переключении темы просто вызовите:
```python
self.setStyleSheet(self.theme_manager.get_stylesheet())
```

## Часто задаваемые вопросы

**Q: Где хранится выбор темы?**
A: В файле `~/.sales_system/theme.json`. Это пользовательская директория вашего ПК.

**Q: Можно ли добавить новую тему?**
A: Да! Добавьте новую запись в словарь `THEMES` в файле `utils/theme_manager.py`

**Q: Почему некоторые элементы не меняют цвет?**
A: Убедитесь, что элемент использует `setObjectName()` для установки имени и его стиль определен в `get_stylesheet()`.

**Q: Совместима ли система тем с другими окнами?**
A: Да! Любое окно может использовать `ThemeManager`. Просто импортируйте его и применяйте стили.

## Примеры использования

### Применить тему к главному окну
```python
from utils.theme_manager import ThemeManager

class MyWindow(QMainWindow):
    def __init__(self):
        super().__init__()
        self.theme_manager = ThemeManager()
        self.setStyleSheet(self.theme_manager.get_stylesheet())
```

### Переключить тему
```python
def toggle_theme(self):
    current = self.theme_manager.get_theme()
    new_theme = "dark" if current == "light" else "light"
    self.theme_manager.set_theme(new_theme)
    self.setStyleSheet(self.theme_manager.get_stylesheet())
```

### Получить цвет из темы
```python
colors = self.theme_manager.get_colors()
accent_color = colors['accent']
```
